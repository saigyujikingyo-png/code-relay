## Schema measurement and initial cloud evidence

The compact serialized output-schema catalog is 20,147 UTF-8 bytes, including tool-name keys. Individual schemas: status 2,974; plan 2,418; run 3,541; job 3,541; result 3,078; cancel 3,456; setup 1,035 bytes. This is not token billing or a quota-savings measurement. Input schemas and other host context are additional.

The saved **Chembridge / Code Relay** environment is bound to the public repository, universal image, Python 3.12, caching, and `bash scripts/setup_codex_cloud.sh` for setup and maintenance. Agent networking uses the common-dependencies preset and GET/HEAD/OPTIONS only. No provider secrets or private environment variables were added. The environment was read back in its detail page and list.

At commit `aff167c50cbeddf3b20fb4a023596e73dfbda0d8`, the interactive container reported Python 3.12.13, Linux 6.18.35; 81 tests in 4.459 s, OK (1 skipped), real stdio passed, loopback self-test passed with two calls, unchanged workspace and 45 ms core elapsed time. The headless Tk class is skipped; its five GUI methods are not counted as executed tests. Setup and maintenance passed. The terminal's `git rev-parse HEAD` confirmed that commit. This initial cloud result predates the added output contracts.

[Initial six-job Windows/Ubuntu CI](https://github.com/saigyujikingyo-png/code-relay/actions/runs/34872326755) also passed Python 3.11, 3.12 and 3.13 at that initial commit. New results must be recorded against the later contract commit rather than relabeling these historical passes.

Direct TLS is implemented; environment proxy inheritance is not. API responses remain untrusted, and no automatic apply/test/git/deploy operation exists in the core. Job receipts stay in private local state. The preview does not validate every university or model entitlement, other agent hosts, a fresh device, full upgrade/removal or ChatGPT Work delivery.
