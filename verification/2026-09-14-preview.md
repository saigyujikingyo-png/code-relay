Commands: `python -m unittest discover -s tests -q`, `python scripts/smoke_mcp.py`, `python -m code_relay self-test`, `python scripts/check_release.py`. The official local plugin and skill validators also passed using an isolated PyYAML dependency.

Observed and fixed during development: Windows stat/fstat ctime differences, transient file-sharing conflicts, cross-run concurrency overflow, cancellation/publication race, oversized serialized plans, common JSON/YAML credential formats, duplicate JSON members, dropped usage on invalid candidates, linked installation destinations and corrupted runtime reuse. Focused regression tests accompany these changes.

Direct TLS is implemented; environment proxy inheritance is not. API responses remain untrusted, and no automatic apply/test/git/deploy operation exists in the core. Job receipts stay in private local state. The preview does not validate every university or model entitlement, other agent hosts, a fresh device, full upgrade/removal or ChatGPT Work delivery.
