## Installation and host compatibility boundary

Same-device installation and update were verified through official Codex plugin commands. The enabled installed runtime matched the public executable hash and passed real stdio discovery, invocation, output validation and text fallback. This does not cover a fresh device, full removal or human GUI usability.

A real Codex model session successfully invoked the installed `relay_status` and received contract 1.0 with structured/text parity. This used the same runtime implementation before the final offline-guide refresh. However, the bounded acceptance prompt requested only that call and the model also made an unrelated read-only discovery call. Status-tool callability therefore passed; first-attempt compliance with the constrained workflow did not. No repeat was used to relabel the result. Detailed host/account usage and installation metadata remain private. The six other tool/model workflows, representative Terra max coding-quality benchmark, cost comparison and live API-provider acceptance remain unverified.
